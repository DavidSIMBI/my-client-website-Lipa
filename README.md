# LipaGo

## Week 3 – Semantic HTML Prototype

### Pages created

Home (`index.html`), About (`about.html`), and Contact (`contact.html`).

### Navigation

A navigation menu appears on every page and lets visitors move between Home, About, and Contact.

### Semantic HTML elements used

- `header` introduces the site and contains the brand.
- `nav` contains the main navigation links.
- `main` contains the primary content for each page.
- `section` groups related page content.
- `article` presents self-contained content such as marketplace features and values.
- `footer` contains the site copyright information.

### Form

The Contact page contains a form that collects a visitor's full name, email address, phone number, and message.

### Accessibility

The prototype uses a language attribute, logical heading levels, semantic page structure, descriptive links, visible keyboard focus styles, and labels connected to every form input. No project images were provided; if meaningful images are added later, they should include useful alternative text.
